# Baselines and ablations

Generated by `eval/OfacMatch.Evaluation --baselines` against the SDN list downloaded 2026-11-03 (19,484 entries), on the development set (seed 42): 4,255 variations, 2,159 harder variations, 2,000 two-part and 1,000 three-part ordinary names, and 1,000 near-miss names. See [the evaluation protocol](evaluation-protocol.md).

Every method below sees the same normalized name parts (accents removed, upper case, list order turned into natural order, legal forms removed for companies), screens against every primary name and alias of the searched type, and keeps the best-scoring name per entry. Only the comparison differs. Scores are on a 0-100 scale, rounded to one decimal. Baselines compare against every listed name; OfacMatch rows use its first-letter pre-filter unless stated.

Methods:

- **Exact match:** 100 if the normalized names are identical, otherwise 0.
- **Levenshtein:** 1 minus edit distance divided by the longer length, whole name.
- **Jaro-Winkler:** Jaro-Winkler similarity of the whole names (OFAC's Technique 1 alone).
- **Token sort ratio:** Indel similarity after sorting the name parts alphabetically, as in RapidFuzz's token_sort_ratio.
- **Token set ratio:** RapidFuzz's token_set_ratio: 100 when one name's parts are a subset of the other's, otherwise the best Indel similarity of the shared and differing parts.
- **Soundex parts:** Share of searched parts that pair one-to-one with a listed part of the same Soundex code.
- **Monge-Elkan (Jaro-Winkler):** Mean, over searched parts, of the best Jaro-Winkler similarity with any listed part.
- **Trigram TF-IDF cosine:** Cosine similarity of character-trigram TF-IDF vectors, with IDF from all listed names.
- **OfacMatch, OFAC FAQ style:** Higher of whole-name and name-parts score, without the guard, with the pre-filter.
- **OfacMatch (default):** Name parts with Soundex, length weights, coverage, extra searched parts allowed, whole-name score behind the guard, and the first-letter pre-filter.
- **– without extra-part rule (0.1.2):** Default, but extra searched parts count as misses, as in version 0.1.2.
- **– without pre-filter:** Default, but every listed name is compared.
- **– without Soundex:** Default, but parts that sound alike get no boost.
- **– equal part weights:** Default, but every searched part counts the same regardless of length.
- **– without coverage:** Default, but no adjustment for how much of the listed name was covered.
- **– name parts only:** Default, but the whole-name score is never used.
